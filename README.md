# WeaveAI

Web 应用位于 `server/`，采用 Laravel 13 / PHP 8.4、Inertia 3、Vue 3 和 Tailwind CSS 4。产品范围见 `plan.md`。

## 本地运行

```sh
cd server
composer install
npm ci
cp .env.example .env
php artisan key:generate
# 在 .env 中填写本机 MySQL 专用数据库、用户名与密码，以及 Redis 配置
php artisan migrate
npm run build
php artisan serve
```

只对本项目专用数据库运行迁移。不要覆盖已存在的 `.env`。Web 根目录为 `server/public/`。开发时另开终端运行 `npm run dev`。

## 检查

```sh
cd server
php artisan test
npm run typecheck
npm run build
npm run format:check
php vendor/bin/pint --test
```

PHP 测试使用独立内存 SQLite，不连接本机业务库。本次脚手架生成的本地 `.env` 仍使用 SQLite；生产与本机 MySQL/Redis 配置模板见 `.env.example`。本会话沙箱禁止本机端口连接，因此尚未验证 MySQL/Redis 连通性。

## 已实现与待开发

已实现首页、注册/登录/退出、文字生图、图片编辑和 5 秒照片动画任务记录、个人任务分页及任务详情授权。参考图支持上传（JPG/PNG/WebP，最大 10MB，宽高不超过 8192），上传与访问均校验登录身份，任务提交校验图片归属。提交包含 UUID 幂等键，同一用户重复提交不重复创建；同一键更换参数会被拒绝。任务状态为 `pending`，不调用模型、不投递推理队列、不生成虚假结果，也不扣费。

钱包报价/预占与生成结算、充值支付暂缓；个人创作记录与素材库已接入，生成产物的预览、下载和输出审核等待结果接口提供后实现。新资产默认使用 Cloudflare R2，公开对象使用随机 UUID 文件名；旧本地资产按记录中的磁盘继续读取。生命周期策略尚待接入。模型执行接口等待提供；届时需实现报价、执行认领、结果回报、失败释放与单次结算，不直接更改现有任务为成功。

`AGENTS.md` 保留原文，其中的 `web/` 为初始建议；依据后续指示，实际 Web 目录统一使用 `server/`。

## 管理后台

访问 `/admin/login`。首次在 `server/` 执行以下命令创建独立管理员（交互输入至少 12 位密码）：

```sh
php artisan admin:create admin@example.com --name=Administrator --role=superadmin
```

后台已有概览、任务元数据查询、用户姓名/邮箱查询和登录/退出审计。任务列表不默认暴露提示词或参考图片。初始角色权限定义于 `server/config/admin.php`：`superadmin` 可查看全部现有后台页面，`operations` 可查看任务，`support` 可查看用户与任务。审计列表仅超级管理员可访问。账号停用会立即阻止后续后台访问；角色与权限映射由代码配置维护，超级管理员可在 `/admin/accounts` 变更其他管理员的角色与启停状态。

后台以 Soybean Admin 为视觉参考，独立实现顶部用户导航、分组侧栏、面包屑、可关闭页面标签与右侧滚动工作区；手机端使用抽屉菜单。菜单及概览快捷入口按权限显示，采用固定浅色卡片与蓝紫色强调色，不提供 UI 配置面板。概览统计沿用真实业务数据，不展示模拟运营指标。

用户端 Tailwind 和后台 Naive UI 使用独立 Vite 入口；用户浏览页面不加载后台组件。数据库迁移新增 `admin_users` 和 `admin_audit_logs`，没有默认密码或种子管理员。

## 模板库

用户入口 `/templates` 支持按标题搜索、分类和创作类型筛选；详情页可套用到工作台。只有已发布模板对用户可见。

具有 `templates.manage` 权限的管理员可在 `/admin/templates` 新增、编辑、提交审核、发布与下架。保存内容必须提供来源授权记录和修改原因；状态操作必须填写原因，均写入审计。初始 `operations` 和 `superadmin` 角色具备此权限。

模板编辑保存独立新版本并退回草稿；历史版本不覆盖。任务保存模板 ID 与版本号，新任务拒绝已下架或过期版本；相同请求的幂等重试仍可返回已记录任务。并发编辑通过版本校验拒绝覆盖。模板支持封面、标签筛选与排序，封面和标签随内容版本保存。

## 钱包与内部额度

用户入口 `/wallet` 提供可用点数、预占点数与个人流水；财务入口 `/admin/wallet` 支持按用户 ID 查询与追加调整。`finance`、`superadmin` 具备 `wallet.manage` 权限，运营和客服不能调账。可通过 `admin:create ... --role=finance` 创建财务管理员。

调整使用整数点数，单次绝对值不超过 1,000,000，余额上限 1,000,000,000；原因必填。余额、唯一业务流水与操作审计在同一数据库事务内写入，并锁定所属用户以串行化余额变化。同一用户的相同幂等标识只能执行一次；改变金额、原因或操作人会被拒绝。错误通过新的反向流水修正，系统不提供覆盖或删除历史流水的入口。账本按自增序号展示，避免同秒变动乱序。

当前没有真实支付入口，提交任务不使用余额。`reserved` 为后续预占预留字段，实际报价、预占和执行结算尚待接入。SQLite 自动化测试验证事务结果与权限，但不能证明 MySQL 并发锁行为；该项需本机服务联调。

## 任务取消与客服

工作台可取消本人的 `pending` 任务；取消以数据库锁保护，只追加一次 `user.cancelled` 事件。其他状态拒绝取消，接口不调用模型或变动账本。未来接入任务预占后，取消需同步释放预占，不能直接沿用当前无扣费流程。

用户可从 `/support` 提交问题，或从工作台关联自己的任务。工单与回复均支持幂等重试；每个用户仅能访问自己的工单。`/admin/support` 仅向 `support.manage` 权限开放（初始客服与超级管理员），支持状态筛选、回复并标记处理中/已解决，回复操作写入审计。用户对已解决工单追问会重新打开；重复发送旧的客服回复不会覆盖新的状态。

当前没有邮件通知或工单附件，沟通记录在页面内查询。用户端和后台复用纯 Vue 工单详情组件，后台页面按需加载。

## 账号设置与停用

用户在 `/settings` 修改昵称及密码；修改密码需要当前密码与两次一致的新密码（至少 12 位）。新密码保存后更新当前会话，其他会话在访问受保护页面时因密码状态不匹配退出。当前不提供邮箱变更或邮件找回密码。

超级管理员可在 `/admin/users` 停用/恢复普通用户，在 `/admin/accounts` 调整其他管理员的角色与启停状态。原因必填，操作追加审计；角色候选值来自 `config/admin.php`。禁止通过管理页面修改自己的角色/启停状态。管理员相互变更时按 ID 顺序锁定双方记录，并在事务内重新校验操作者权限，避免已被撤权的管理员继续提交变更。

用户启停字段不在用户资料的可写字段内。停用用户不能重新登录，已有 Web 会话会在后续请求中退出；停用不删除任务、资产、账本或工单。管理员停用同样在后续后台访问中生效。

## Cloudflare R2 资产存储

依据当前要求，文件使用**公开访问的 R2 桶**，对象路径为 `assets/<随机 UUID>.<校验后的扩展名>`，不使用原始文件名、用户 ID 或连续编号。Web 的资产记录与任务访问仍受权限控制，但公开对象 URL 持有人可以直接访问文件；该约定覆盖 `plan.md` 初版的私有存储方案。

在 `server/.env` 填写（不要将凭据提交到仓库）：

```dotenv
ASSET_DISK=r2
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET=
R2_ENDPOINT=https://<ACCOUNT_ID>.r2.cloudflarestorage.com
R2_PUBLIC_URL=https://<公开访问域名>
```

R2 使用 `auto` 区域，已安装 Flysystem S3 适配器。公开域名应指向配置的桶，不是 S3 API 端点。参考 [Cloudflare S3 API 文档](https://developers.cloudflare.com/r2/api/s3/api/)。当前文件经服务端校验并上传，浏览器不接触 R2 凭据。自动化测试模拟 R2；真实凭据、上传和公开域名尚未联调。开发需完全离线时可显式设置 `ASSET_DISK=local`，此时本地文件仍通过登录校验读取。

## 输入审核

后台任务列表支持审核状态筛选和详情。初始 `reviewer` 与 `superadmin` 可查看输入、审核通过/拒绝；其他具备任务查询权限的角色仅查看元数据。查看输入及参考图、提交审核结论写入审计。

审核结论只追加一次，重复请求幂等，不能直接覆盖已有结论。拒绝将任务标为 `rejected`，同一用户再次提交相同规范化提示词、任务类型及参考图内容会被拦截；这只是相同输入的防重放措施，不替代完整内容检测。申诉可走客服工单。审核通过保持待处理，不调用模型、不扣费。文件已按要求公开存储，审核结论不会撤回公开对象链接。

## 运营公告与帮助中心

运营及超级管理员可通过 `/admin/content` 新建帮助文章和首页公告。内容以纯文本展示，支持草稿预览；保存新版本不会替换已发布版本，发布与撤回均要求原因并记录审计。路径标识创建后固定，编辑和发布通过版本号防止覆盖他人的更新。

首页展示最近 3 条已发布公告，`/help` 分页展示已发布帮助文章，`/help/<slug>` 查看详情。撤回后内容不再公开展示，历史版本仍保留。充值渠道尚未确定，充值及支付功能继续暂缓。

本地脚手架 SQLite 数据库已执行当前全部迁移，应用内请求验证首页、帮助中心、模板库、用户登录和管理员登录均返回 200。该检查不代表 MySQL/Redis、真实 R2 或浏览器交互联调已完成。

## 模板封面与分类展示

模板后台可上传 JPG/PNG/WebP 封面（不超过 10MB、宽高不超过 8192），图片沿用 R2 UUID 对象命名与公开访问策略。封面记录独立于用户输入资产，避免误将用户参考图作为运营封面。上传操作写入审计。

每个模板版本可设置最多 12 个标签（单个最多 30 字符）及 0–1,000,000 的排序值；值越小，用户目录越靠前。目录支持标签筛选，列表和详情均展示已发布版本的封面与标签。未发布封面的应用入口只有模板管理员可访问；R2 对象 URL 本身仍按公开桶策略处理。

## 我的创作与素材库

`/works` 按任务类型、状态筛选个人创作记录，`/works/<任务 ID>` 查看输入、原模板版本、审核原因与最近任务事件。当前仅展示真实任务记录，尚无生成产物。

`/assets` 分页展示个人上传图片、任务引用数量，并可选择图片回到工作台复用。用户仅能删除未被任务引用的素材；引用中的图片暂时保留，防止破坏任务追溯。删除先在事务内锁定所属用户并标记 `deleting`，再删除存储对象，成功后标记 `deleted`。存储失败可重试；删除中的素材不能用于新任务。提交任务在相同用户锁内重新校验素材状态，避免与删除竞争。

R2 删除针对源对象；已公开文件的浏览器或 CDN 缓存不由此数据库状态自动撤销。原有公开桶约定保持不变。

## 创作参数与接单控制

工作台可记录画面比例；照片动画记录期望 5 秒。参数与接单配置版本保存在任务中，用户详情与有输入权限的后台详情可追溯。此阶段参数表示用户意图，尚未连接实际模型，不承诺模型执行能力。

`/admin/generation-modes` 允许运营与超级管理员暂停/恢复某类任务接单、调整比例选项和暂停提示。更新需填写原因并追加审计，版本校验防止覆盖更新。暂停仅阻止新任务；已记录任务的幂等重试仍返回原记录。不同参数不能复用同一提交标识。

每用户默认最多 10 个等待处理/处理中任务，环境变量 `GENERATION_PENDING_LIMIT` 可调整。检查与任务创建共用用户行锁，防止并发突破上限。超限后可取消未处理任务。任务提交仍不调用模型，不投递推理队列，也不预占或扣费。

## 运营报表与迁移检查

`/admin/reports` 支持按 UTC 自然日查询 1–93 天的注册、任务创建、任务类型与当前执行/审核状态，含每日趋势表。状态统计针对期间创建任务的当前状态，不是历史时点快照。运营、财务及超级管理员可访问，客服和审核员无此权限。

财务与超级管理员额外查看期间点数增加、扣回、净变动和当前钱包汇总；金额字段以整数字符串传输。运营响应不包含财务值。点数调整不计作充值或现金收入，当前仍无真实支付收入指标。

已在独立临时 SQLite 数据库验证全部迁移的创建、回滚和重建；该结果不代表 MySQL 迁移或并发行为已验证。报表日期条件为开始日含、结束日下一日不含，并为主要统计表增加日期索引。

## 布局、多语言和主题

用户界面参考 https://cling-ai.com 的创作平台结构：固定侧边导航、顶部工具区、双创作入口和模板推荐网格，保留 WeaveAI 品牌；示意视觉由 CSS 绘制，未复制参考站图片。手机端可收起导航，阿拉伯语使用 RTL 排版。首页优先显示后台已发布的模板封面。

用户端默认语言为英文。与参考站一致提供 `en/de/ja/ko/es/ar/fr/pt/id/hi/vi/nl/pl/tr/it/no/fil`，另加 `zh`。用户端只有 `APP_DEBUG=true` 时接受中文设置并显示中文选项；关闭 debug 后用户端已有中文 Cookie 也回退英文。管理后台（含登录页）默认使用简体中文，始终允许选择中文，并通过独立的 `admin_locale` Cookie 保存后台语言，不跟随用户端语言。主要导航、首页、登录与创作操作已本地化，缺少的词条使用英文回退。运营文章、模板标题与用户输入保留原内容，不自动翻译。

用户端的明暗主题及用户端/后台各自的语言偏好通过 `/preferences` 保存到一年期 Cookie。用户端默认使用暗色主题；后台使用独立的固定浅色样式，不提供主题或语言配置控件，默认中文，已有后台语言偏好仍有效。HTML 首次响应即设置语言、方向与用户端主题，日期与数字按所选语言格式化。
